# Project notes

- Game-controller research lives under `docs/`. Start at `docs/README.md`; it says which single file to read. Do not read `docs/game-client/` or `docs/data/*.json` in full.
- To see one method's source use `node scripts/bundle-method.js <Ctrl> <method>`.
- `extension/content.js` is generated. Edit `extension/src/content/`, then run `node scripts/build-content.js`.
